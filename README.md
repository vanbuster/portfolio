## 信息架构：为什么是这样

- **第一屏直接是作品**，姓名缩成左上角 14px 小字，联系方式沉到页脚。
  实测 15 个同类站点，**没有一个**用悬浮联系按钮；姓名的主流做法是"错位"
  （小字 logo 承担识别，巨型姓名放在作品之后）而不是放大。
- **列表而不是网格**。作品只有 3 个，3 格网格会显得空旷、像未完工。
  列表 + 悬停跟随预览是这个数量级的正解：靠字号建立层级，靠预览图提供信息。
- **一句话 10–18 字**。业界收敛在"动名词+结果"或"名词短语+硬证据"两种句式，都极短，
  标题 + 一句话完全够，多写就是稀释。

**两条纪律**：

1. **低彩度**。饱和度一高立刻变"科技蓝"，油画感全失。着色器实测饱和度均值 **0.35**。
2. **正文用暖白不用纯白，描边不用黑**（用底色 + 透明度）——印象派里没有纯白和黑轮廓线。

正文 `#e0dcc8` 在着色器最亮处实测对比度 **5.28:1**，过 WCAG AA。

## 技术选择

| 选择 | 版本 | 为什么 |
|---|---|---|
| GSAP + ScrollTrigger | 3.15.0 | 滚动驱动事实标准；3.13 起全部插件免费 |
| Lenis | 1.3.26 | 惯性平滑滚动，19KB |
| 手写 WebGL 着色器 | — | 域扭曲做水面。Three.js 650KB；OGL 是源码型 ESM（入口 `src/index.js`，不是 `dist/`），CDN 引入要拉几十个文件。手写约 4KB |

**核验后排除**：curtains.js（维护放缓，作者转向 WebGPU）、hover-effect.js（2023 年后停更且锁死 three r149）、Theatre.js（近两年无更新）。

CDN 全部走 jsDelivr，**逐个 curl 实测返回 200 且校验过字节数**。

## 踩过的坑（改之前先读）

1. **噪声不归一化 = 整屏黑**
   `fbm()` 以 0 为中心（约 `[-0.6,0.6]`），取色前必须 `*0.5+0.5`，
   否则 `smoothstep(0.30,0.86,n)` 几乎全被钳成 0。

2. **权重相关 = 整屏一个色**（更隐蔽）
   驱动各色的噪声场如果彼此派生（拿 `o1`/`o2`/`f` 当权重），它们高度相关，
   所有颜色出现在同一批位置 → **实测色相跨度只有 13°**，就是一片蓝雾。
   必须给每色一个**独立偏移的噪声场**，且用归一化加权而非链式 `mix()`
   （`mix` 四次之后收敛成平均色）。修完 55°。
   附带教训：`pow()` 锐化权重反而更糟（36°→24°），会让主色通吃。

3. **深色图不能再叠暗色 multiply**
   浅色截图叠一层水色能"沉进水里"，但自制的深色图表叠完只剩 22/255，像块黑板。
   `.fig.native` 就是这个豁免类。

4. **悬停预览必须约束在右侧带内**
   纯跟手会盖住它正在预览的那行标题（第一版就把 "PRD Copilot" 遮掉一半）。
   现在 clamp 到 `innerWidth * 0.63` 以右。

5. **Lenis 的选项叫 `syncTouch` 不是 `smoothTouch`**
   `smoothTouch` 是 v0.x 旧名，1.3.26 里根本没这个键，传进去被**静默忽略**——
   属于"看起来配了实则没配"的隐性坑。

6. **别在 `pointermove` 里量正在被变换的元素**
   `getBoundingClientRect()` 返回的是变换后的包围盒（实测 rotate 16° 让宽度涨 17.6%、
   左边界移 29px），拿它做归一化会正反馈抖动，且每帧强制同步布局。
   改为 `pointerenter` 量一次并缓存。

7. **Lenis 和 ScrollTrigger 必须共用一个 rAF**
   各跑各的会差一帧，视差会抖。现在 Lenis 挂在 `gsap.ticker` 上，
   并且 `lenis.on('scroll', ScrollTrigger.update)`。

8. **锚点跳转要走 Lenis**
   原生 `scrollIntoView` 和惯性滚动打架，已接管所有 `a[href^="#"]`。

9. **`background-clip:text` + 逐字拆分 = 标题消失**
   渐变基于每个 span 各自的盒子重算，整行变透明。要逐字动画就别用渐变文字。

## 无障碍与降级

- `prefers-reduced-motion: reduce` → 关全部动画、WebGL 降级为静态 CSS 渐变、揭示元素直接显示
- WebGL 不可用 → 同上，内容完全不受影响
- 移动端 DPR 限制 1.25，避免高分屏填充率掉帧
- 着色器滚出视口即停（IntersectionObserver 观察的是**随页面滚动的容器**，
  不是 `position:fixed` 的 canvas —— 观察 fixed 元素会恒定 `isIntersecting=true`，
  "滚走就停"永远不触发）
- 移动端隐藏悬停预览（`@media (hover:none)`）

**实测**：desktop 1440×900 与 mobile 390×844 均无横向溢出、无页面错误、无失败请求。
